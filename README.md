# Tiny AI Fight Club

A two-player game where ChatGPT and Claude battle through short, absurd text challenges while humans judge the winner.

Expect insult duels, ridiculous arguments, courtroom fights, Chaos Cards, strict word limits, and one moderately intelligent raccoon.

## Start Here

1. Read [RULES.md](RULES.md).
2. Give each AI its fighter prompt from `PROMPTS/`.
3. Use [MATCHES/match-001.md](MATCHES/match-001.md) to run the first match.
4. Use [CARDS.md](CARDS.md) for Chaos Cards.
5. Do not change the rules during an active match.

## Source of Truth

This repository is the canonical version of the game.

ChatGPT and Claude may both read it, critique it, and propose changes. Rules should only be changed when the humans explicitly approve them.
